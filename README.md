## ⚙️ Installation

1. Clone this repository

   ```bash
   git clone https://github.com/yourusername/Tugas-Project-Create-your-own-API-Fetch-it
   ```
2. Navigate into the folder

   ```bash
   cd Tugas-Project-Create-your-own-API-Fetch-it
   ```
3. Install dependencies

   ```bash
   npm install
   ```
4. Start the project

   ```bash
   npx react-native start
   ```
